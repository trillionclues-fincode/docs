---
title: 'External Screening Webhook'
openapi: 'POST /compliance/external-screening/webhooks/{provider}'
description: 'Receives verification results from an external KYC provider and closes the outstanding compliance rule.'
---

Configure this URL as the webhook callback endpoint in your KYC provider account settings. This is a one-time setup per provider, not per customer.

When the customer completes verification with your provider, the provider calls this endpoint. RemitJunction uses the `providerReference` field in the payload — which must be the reference returned from the [Initiate External KYC Provider](/api/ciam/initiate-external-provider) endpoint — to locate the correct customer record and close the outstanding KYC rule.

## Path Parameters

| Parameter | Description |
|-----------|-------------|
| `provider` | The provider code assigned to your KYC provider by RemitJunction |

## Behaviour

| Provider Decision | Outcome |
|-------------------|---------|
| `APPROVED` | KYC rule is marked as submitted and the compliance record is updated |
| `DECLINED` | KYC rule is reset so the customer can retry verification |
| `PENDING` / `REVIEW` | Event is acknowledged but no action is taken — only final decisions are processed |

## Requirements

The webhook payload must include the `providerReference` field containing the reference UUID generated by RemitJunction when the session was initiated. Without it, the result cannot be matched to a customer and will be rejected.
