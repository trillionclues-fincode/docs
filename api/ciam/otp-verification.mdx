---
title: 'OTP Verification'
openapi: 'GET /securitymanagement/otp-verification/{email}/{verification-code}'
description: 'Verifies a one-time password submitted by the customer for email or phone number verification.'
---

When an email verification compliance requirement is initiated, RemitJunction sends an OTP to the customer's email address. Your system must:

1. Provide a field for the customer to enter the OTP code
2. Submit the code to this endpoint

On success, the `VERIFY_ACCOUNT_VIA_EMAIL` KYC rule is marked as complete in the customer's compliance record.

## Path Parameters

| Parameter | Type | Required | Validation | Description |
|-----------|------|----------|------------|-------------|
| `email` | String | Yes | — | The customer's registered email address |
| `verification-code` | String | Yes | Min 3 characters | The OTP code received by the customer via email or SMS |
