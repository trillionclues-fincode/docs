---
title: 'Verify Customer'
openapi: 'GET /admin/customer-management/verify-customer/{id}'
description: 'Manually verifies and activates a customer account. Requires MANAGER or ADMIN token.'
---

Marks a customer account as verified. The `{id}` path parameter is the customer's userId (UUID).

Only `ADMIN` and `MANAGER` tokens are accepted.

## Path Parameters

<ParamField path='id' type='string' required>
  The customer's `userId` (UUID) — the `userIdKey` value from the register-customer or list-customers response.
</ParamField>

## Request Headers

<ParamField header='X-Auth-Token' type='string' required>
  JWT Access Token of an authenticated manager or admin.
</ParamField>

<ParamField header='platform' type='string' required default='fincode'>
  Platform identifier. Use `fincode`.
</ParamField>

<ParamField header='uuid' type='string' required default='200'>
  Unique request identifier.
</ParamField>

## Code Example

```bash cURL
curl -X GET 'https://{your-domain}.fincode.software/api/v6/services/admin/customer-management/verify-customer/{userId}' \
--header 'X-Auth-Token: YOUR_JWT_ACCESS_TOKEN' \
--header 'platform: fincode' \
--header 'uuid: 200'
```
