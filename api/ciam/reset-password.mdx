---
title: 'Reset Password'
openapi: 'GET /securitymanagement/reset-password/{email}'
description: 'Sends a password reset email to the customer. No authentication required.'
---

Triggers a password reset email to the specified email address. No `X-Auth-Token` is required — this is a public endpoint called before login.

The email must belong to a registered customer on the pay centre domain.

## Path Parameters

<ParamField path='email' type='string' required>
  The email address of the customer who wants to reset their password.
</ParamField>

## Request Headers

<ParamField header='platform' type='string' required default='fincode'>
  Platform identifier. Use `fincode`.
</ParamField>

<ParamField header='uuid' type='string' required default='200'>
  Unique request identifier.
</ParamField>

## Response

<ResponseField name='status' type='string'>
  `SUCCESS` if the reset email was sent, `FAILED` otherwise.
</ResponseField>

<ResponseField name='message' type='string'>
  A description of the result.
</ResponseField>

## Code Example

```bash cURL
curl -X GET 'https://{your-domain}.fincode.software/api/v6/services/securitymanagement/reset-password/customer@example.com' \
--header 'platform: fincode' \
--header 'uuid: 200'
```
